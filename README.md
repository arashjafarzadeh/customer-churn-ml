# Customer Churn Prediction & Actionable Customer Ranking

An end-to-end machine learning project for predicting customer churn probability and ranking customers based on their risk of churning.

## Project Status

🚧 Project is currently under development.

## Goal

Build a production-oriented machine learning system that can:

- Predict the probability of customer churn.
- Rank customers by churn risk.
- Support actionable customer retention decisions.
- Follow a complete ML lifecycle from data acquisition to deployment and monitoring.
